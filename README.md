# Salesforce Subscription Renewal Management

## Overview
A Salesforce application that automates subscription lifecycle management, including subscription creation, renewal tracking, and renewal opportunity generation.

## Features
- Subscription & Subscription Item custom objects
- Record-triggered Flow for automatic Subscription creation
- Scheduled Flow for Renewal Opportunity generation
- Validation Rules
- Lightning App
- Git & Salesforce DX

## Tech Stack
- Salesforce Platform
- Flow Builder
- Apex (Coming Soon)
- Lightning Web Components (Coming Soon)
- Git & GitHub
